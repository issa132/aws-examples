# AWS Amplify
AWS Amplify is an opinionated framework and fully-managed infrastructure to allow developers to focus on building web and mobile applications.
AWS Amplify CLI — unified toolchain to create, integrate, and manage the AWS cloud services
AWS Amplify SDK — connects AWS Services to your client-side code.
AWS Amplify UI — A collection of accessible, themeable, performant React components directly connect to cloud
AWS Amplify Hosting — a static website hosting platform
AWS Amplify Studio — visual development environment for building fullstack web and mobile app
AWS Amplify has direct integrations with:

Amazon Cognito — For auth sigin and signup
API Gateway — For rest APIs
AppSync — For GraphQL APIs
S3 — For Storage or for Static Website Hosting
DynamoDB — For a backend database
AWS Lambda — custom resolvers

Amplify works with the following js frameworks:

JavaScript
