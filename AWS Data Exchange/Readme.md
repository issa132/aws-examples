#  AWS Data Exchange


AWS Data Exchange is a catalogue of third-party datasets. You can download for free subscribe or purchase datasets. Eg. COVID-19 Foot Traffic Data, IMDB TV and Movie data, Historical Weather Data

    Upload your own data sets for sale in the AWS Marketplace
    Data grants allow you to control access to your datasets.

Data sets pricing can be:

    Free
    Upfront Commitment
    Usage based

Open Data on AWS program is a collection of over 300 free, publicly available data sets.
