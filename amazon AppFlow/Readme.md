Amazon AppFlow is managed integration service for data transfer between data sources. Easily exchange data with over 80+ cloud services. By specifying a source and destination.

Flow Triggers:

    Run on demand — Users manually run the flow as needed.
    Run on event — Amazon AppFlow runs the flow in response to an event from an SaaS application.
    Run on schedule — Amazon AppFlow runs the flow on a recurring schedule.

Features

    Create dataflows between application within minutes
    Aggerate data from multiple sources
    Data can be encrypted-at-rest and in-transit.
    Use partition and aggregation settings to optimize query performance
    Develop custom connectors via the Amazon AppFlow Custom Connector SDKs
    You can create private flow via AWS PrivateLink
    You can catalog data transfered to S3 via AWS Glue Data Catalog
