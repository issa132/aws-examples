AWS Device Farm
AWS Device Farm is an application testing service to test your applications in different environments.
Mobile Device Testing

You can test Native iOS (.ipa) or Android (.apk), or Mobile Web-Apps
You can utilize built-in tests Fuzz which will randomly test actions
Videos will be capture of runs
Screenshots will be captured of run
You can choose multiple devices

AWS own physical phones that you virtually connect to


You can remotely connect to a phone and upload your app to do general troubleshooting against a real phone.
You can test using a suite of test using Appium

Appium Java Junit
Appium Test NG
Appium Python
Appium Node.js
Appium Ruby



Desktop Browser Testing

You can test your web-application against multiple web-browser
